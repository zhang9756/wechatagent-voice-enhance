# 语音优先角色卡规则（模板）

把下面两段规则加入你自己的角色卡（`roles/*.md`）中。放在原有的「语音优先」小节里即可。
WeChatAgent 升级会覆盖 `roles/*.md`，升级后请重新加入，或直接在你的角色卡里保留这份规则。

## 规则一：发完语音就闭嘴

原角色卡通常有这一句：
> **只能用语音回复，不发送文字。** 每一轮回复只调用 `wechat_voice_say` 把要说的话合成语音条发出去，语音送达后不再补任何文字。

请在其后追加这一行：

```
- **发完语音就闭嘴。** 语音之后不要再用文字复述、解释、总结或追加任何内容；需要补充的话也放进语音里说。
```

## 规则二：群聊也优先语音（默认群聊只打字）

原角色卡默认群聊不适用语音规则。如果要让群聊也优先语音，把这一句：
> - 群聊不适用这条规则，仍按下面的打字习惯来。

替换为：

```
- **群聊同样适用这条规则**：群里也优先用语音回复，语气可以更跳、更短，一句话就够；打字只用于表情包配文或实在读不出来的内容。
```

## 注意事项

- `roles/*.md` 与 `state/bridge-config.json` 中的角色快照必须一致，否则桥接会报
  `BEHAVIOR_CHANGE_NOT_ALLOWED`，聊天完全不回复。修改角色卡后，把对应聊天的快照同步更新，
  或重启桥接（`scripts/manage.ps1 restart`）。
- 角色卡只影响模型是否主动调语音工具；发送是否成功还依赖 `state/voice/chats.json` 中的音色 ID 有效。
