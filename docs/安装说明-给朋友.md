# WeChatAgent 语音音色增强包 · 安装说明（给朋友）

> 本文档面向从 v1.x 或 0.4.0 升级的朋友。按顺序做即可。

---

## ⚠️ 重要前提（先看完再动手）

1. **必须使用 WeChatAgent 0.4.1**
   - 本增强包补丁基于 0.4.1 的官方文件编写。
   - 如果你还是 0.4.0，**直接打补丁会把控制台弄挂**（缺 0.4.1 新增的
     `fish-notebook-console.mjs`、`memory-console.mjs`、`plugin-api` 等文件）。
   - 解决办法：先下载并安装官方 WeChatAgent-Setup-0.4.1-x64.exe，完成升级。
2. **必须有一个 Fish Audio API Key**
   - 到 https://fish.audio 注册账号 → 控制台 → API Keys 免费创建。
   - 没有 Key 就无法在线合成语音。
3. **微信客户端版本必须是 4.1.10.27**
   - 语音版 hook DLL 只针对这个版本编译。0.4.1 官方对应的就是这个版本。
4. 安装前请先**退出微信**（托盘完全退出）。

## ✅ 安装步骤

### 第 1 步：升级 WeChatAgent 到 0.4.1

1. 从官方仓库下载：https://github.com/sourcepro5/WeChatAgent/releases
   下载 `WeChatAgent-Setup-0.4.1-x64.exe`。
2. **退出 WeChatAgent 和 DSH**（托盘退出，不是关窗口）。
3. 运行安装包，按提示完成升级。
4. 升级后打开 WeChatAgent 控制台，确认版本显示 0.4.1。
5. 重新打开 DSH，登录你的账号。

> 如果你是 0.4.1，直接跳到第 2 步。

### 第 2 步：解压增强包

把 `wechatagent-voice-enhance.zip` 解压到任意目录，例如：

```powershell
tar -xzf wechatagent-voice-enhance.zip -C D:\
# 解压后得到 D:\wechatagent-voice-enhance
```

### 第 3 步：一键完整安装（二选一）

**方式 A：双击安装（最简单）**

双击解压目录里的 **`install.bat`**，它会自动完成全部安装。

**方式 B：命令行安装**

以 PowerShell 运行（**管理员不需要**，普通窗口即可）：

```powershell
cd D:\wechatagent-voice-enhance
pwsh -File setup.ps1 -Workspace D:\yu\workspace
```

> `-Workspace` 填你的 WeChatAgent 工作区目录（包含 `config\wechatagent.json`）。
> 如果不填，脚本会尝试自动检测常见路径。

脚本会自动完成：
- 校验版本是不是 0.4.1（不是会提示先升级）
- 部署 `dsh-wechat-voice` 插件到 `packages\` 并注册到 DSH
- 部署 `silk_encoder.exe`
- 部署**语音版 version.dll**（支持 `SendVoiceMsg`）并更新 hook 清单
- 生成 `state\voice\config.json`（Fish Audio 配置模板）
- 打「语音音色」控制台页面补丁
- 重打社区桥接插件补丁（防止微信不回消息）

### 第 4 步：填 Fish Audio API Key

编辑生成的文件：

```
<工作区>\state\voice\config.json
```

把 `"fishApiKey"` 的值换成你在 fish.audio 获取的真实 Key：

```json
"fishApiKey": "sk-fish-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

保存。

### 第 5 步：重开微信（让语音 DLL 生效）

1. **完全退出微信**（托盘图标 → 退出）。
2. 重新打开微信（或到 WeChatAgent 控制台 →「打开匹配微信」）。
3. 登录后确认能正常收发消息。

> 新 DLL 会在微信重新打开时由 hook 部署脚本自动装入。
> 如果微信里语音还是发不出去，可在控制台运行一次「检查发送连接 / 打开匹配微信」。

### 第 6 步：重启 DSH

**托盘退出 DSH，再重新打开**（不是关窗口）。确保新插件被 DSH 加载。

### 第 7 步：使用

1. 打开 WeChatAgent 控制台。
2. 侧边栏找到「**语音音色**」。
3. 在「**全局默认音色**」填一个 Fish Audio 音色 ID（32 位十六进制）。
4. 在「**按聊天设置**」给常用聊天填音色 ID，点「保存全部」。
5. 在「**合成语音并发送**」输入文字、选聊天、点「合成并发送」。

## ❓ 常见问题

### Q1：为什么我之前下载的包装不上 / 微信里收不到语音？

A：v1.x 是**不完整包**，只有控制台页面补丁，缺三样后端组件：
- `dsh-wechat-voice` 语音插件（负责 TTS 合成）
- `silk_encoder.exe`（把 WAV 转成微信语音格式）
- 语音版 `version.dll`（hook 里支持 `/SendVoiceMsg`）

所以即使页面装上了，`POST /SendVoiceMsg` 也会返回 404，语音根本发不出去。
**v2.0 完整包已内置这三个组件**，用 `setup.ps1` 一键部署即可。

### Q2：我是 0.4.0，直接覆盖会怎么样？

A：会挂。0.4.1 的控制台新增了 `fish-notebook`、`memory`、`plugin-api` 等模块，
0.4.0 没有这些文件，直接覆盖 `console-server.mjs` 会导致控制台启动失败。
**请先升级到 0.4.1**。

### Q3：我没有 Visual Studio / MSBuild，能装吗？

A：**能**。语音版 `version.dll` 是预编译好的，包含在包内，不需要你编译。
本机只需有微信客户端和 Fish Audio Key 即可。

### Q4：语音条发不出去，控制台显示什么？

A：请到「语音音色」页面的「**最近发送**」看记录，以及
`<工作区>\state\logs\voice-send.log` 看错误码：
- `Reference not found`：音色 ID 无效，换一个有效 ID。
- `READER_UNAVAILABLE`：读取服务未运行，先到控制台「连接设置」连好微信。
- `HOOK_VOICE_ROUTE_MISSING`：语音 DLL 没生效，按第 5 步重开微信。

### Q5：会不会影响我原来的聊天记录 / 配置？

A：不会。脚本只做备份 + 部署组件 + 打补丁，不动你的聊天记录。
所有被覆盖的文件都会先备份到 `<工作区>\state\console-backups\`。
